## HNR 实验结果

原缺陷来自相关峰高度的三点插值，而非声源存在噪声。按 [Boersma 原始研究关于采样与峰高的讨论](https://www.fon.hum.uva.nl/paul/papers/Proceedings_1993.pdf)核查后，本实现改为对实际重建信号求相关。方法与 Praat 的具体窗口和归一化不同，没有声称等同 Praat。

| 条件 | 修复前 | 修复后 |
| --- | --- | --- |
| 44.1 kHz、237 Hz 多谐波，无添加噪声，Int16 完整流水线 | HNR 约 14.35 dB | 约 60.00 dB，达到数值上限 |
| 44.1 kHz、389 Hz 同类输入 | 约 21.61 dB | 约 60.00 dB |
| 12 kHz 浮点、237 Hz 多谐波、已知 F0、10 dB 白噪声 | 约 8.59 dB | 约 10.12 dB |
| 同条件 20 dB 白噪声 | 约 13.30 dB | 约 20.11 dB |
| 同条件 30 dB 白噪声 | 约 14.24 dB | 约 30.04 dB |

另外，在 89.7、151.3、263.2、431.5、733.1 Hz、最高谐波不超过 5.5 kHz 的新固定条件下，HNR 覆盖率至少 95%、均值至少 50 dB；263.2 Hz 的三个已知白噪声条件均值误差小于 1 dB。这些是针对性数值回归条件，不能作为临床测量范围或正常值。相同条件的重叠帧不是独立受试者。

## 可用性和开销

每次分数延迟点积后可让出异步迭代，取消会传播为 `AbortError`，不会把迟到的分析写回页面。没有改动录音管理器交接，也没有新增校准、过期、输入路由或历史算法拦截。旧实验室预设、无校准录音和保存保持原使用路径。

## 保留的科学性问题

共振峰共同模型偏差、覆盖不足和错误接受尚未解决。本轮补齐其质量语义及验证分母，不能据此宣称修复了共振峰准确性，也没有调整数据集、删掉失败条件或放宽门槛。

12 kHz、10 dB 白噪声的既有核心探针仍能触发 237 Hz 误选约 79 Hz 的三倍周期；44.1 kHz 宽带噪声的三个种子条件未复现该错误，因为分析带内 SNR 不同。本轮 F0 修正针对数值端点，不构成噪声鲁棒性保证。后续应按分析带内 SNR、声源/谱包络和采样率研究周期歧义。

HNR 修补后的纯周期及白噪声结果良好，但有限 sinc 支持、噪声颜色、非平稳音高及振幅扰动仍需要独立研究。60 dB 为数值截断上限。论文和页面继续保留 HNR 的实验性说明，没有追加“实验室级”或“临床级”保证。

本轮 Gemini 仅审核公开的一般理论，没有提供源码或授权文件读取，任务完成且 `command_audit` 为空。采用了有限支持、固定比较区间、带宽和性能验证建议；未采用把 Blackman 主瓣宽度直接当作分数延迟通带误差的推断，也未把模型意见作为测试或临床证据。
