# 录音、记录可用性和页面样式修复

日期：2026-09-28。算法标识：`acoustics-2026-09-28.1`。未提交或推送。

## 录音流程

1. `utils/recorder-session.js` 为每种原生生命周期事件只注册一次监听，页面通过 `observeRecorderEvent` 订阅。这样既支持多个原生监听叠加，也支持仅保留最后一次监听的实现，不再依赖页面直接注册或解绑原生停止事件。
2. 原生停止事件分发结束后才启动下一会话，防止在停止回调内部重入原生启动。
3. 主测量、粗校准、高级校准和语音学页面仅能释放自己持有的录音。旧页面延迟卸载不再停止新页面的录音。
4. 粗校准的采样超时和高级校准的倒计时等待原生启动后才开始。粗校准在启动错误后可直接重试；高级校准的旧确认框不能重启新的校准会话。
5. 语音学页面不再以 JavaScript 停止回调的墙钟延迟判定整段录音不可用。原生时长不一致时保留已接收片段并说明范围，停止显示全段 HNR 和周期变化率。

单监听兼容性模拟在修复前使四个模块全部出现失败，修复后全部通过。该模拟解释了一条可复现的兼容性故障路径，不等同于证明用户设备上的 SDK 一定采用单监听实现。旧页面延迟卸载导致四个模块停止新录音的场景也已复现并修复。

## 校准和记录

- 没有校准条件、校准过期或绑定信息不匹配时，仍能录音、显示估算值和保存记录。记录保留 `calibrationLabel`、`calibrationNote`、`calibrationVerified`，不把估算参数标成已通过本机参考校准。
- 已有实验室预校准继续可用。旧备份导入不再因日期、安装标识或旧采集配置被拒绝；复制和导入时保留实验室来源及原始参数信息。仍检查备份结构及偏移量是否为有效数值。
- 历史记录保留原始数值，通过过时算法标记区分，不改写或清空历史结果。
- 原生时长与样本数一致：`dataQuality: valid`，范围为整段录音；只有参考校准具备风险分级条件。
- 原生时长缺失：`dataQuality: unverified`，允许保存已接收音频的估算记录。
- 原生时长与样本数不一致：`dataQuality: partial`，允许保存已接收片段，明确标记 `measurementScope: received-audio`，页面显示“片段 LAeq”，不进行整段风险分级。
- 没有音频、过载、明确输入故障或停止未确认，仍不会被包装为有效测量。

允许保存片段不代表恢复了丢失的数据。选择性遗漏强声的反例仍可能使片段 LAeq 比完整录音低 10 dB 以上；回归要求该结果明确保留片段范围和中性风险显示，不能标为完整有效测量或“安全”。

## 样式

语音学参数选择、缩放按钮、起止时间输入、说明文字和录音状态卡片增加对应 WXSS 类。高级校准的来源标签、日期、备份按钮、状态文字和数值面板使用页面既有的主题颜色、圆角、间距和字号。小屏幕下的按钮及数据行允许换行。未进行真机或微信开发者工具的视觉验收。

最后追加的“异步停止期间立即跨页启动校准”补验及最终补丁格式检查，因自动审批服务额度耗尽而未取得执行结果，不计入已通过测试。普通沙箱仍存在进程创建故障。额度失败不是安全性拒绝，未绕过审批执行这些命令。

AGY Gemini Pro High 本轮返回空结果，DSH 追加静态复核超时，因此不声称通过独立子代理最终审核。上述通过项来自本地实际运行的测试。
