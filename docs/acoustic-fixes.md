# 声学与言语分析修复说明

以下保留早期静态审查修复记录；最新测试结果与限制以 [2026-09-27 评估报告](algorithm-evaluation-report.md) 为准。早期阶段未执行录音或真机验证，语法检查不能证明测量精度。

| 问题 | 当前处理 |
| --- | --- |
| 共振峰编号错位 | 频率范围外候选不占槽位；范围内带宽不合格候选保留位置，数值留空；跨帧单调匹配。 |
| 高音误识别为低八度 | 基频使用未预加重信号；支持 40–1200 Hz，并搜索范围外候选，越界返回缺失。 |
| CMNDF 被当作 HNR | 改为去均值、限带信号上的重叠能量归一化自相关估计，支持负 dB，估计上限 60 dB。 |
| HNR 筛选偏差 | 不依赖 YIN 有声判定；公布有效帧比例；有能量但无法估计的帧存在时，不输出全段均值。 |
| 非元音污染散点 | 共振峰要求可信有声证据；元音空间要求用户先框选稳定元音片段，不宣称自动识别元音。 |
| LPC 频带不匹配 | 257 点窗化 sinc 抗混叠重采样到 12 kHz，12 阶 LPC，目标共振峰上限 5 kHz。 |
| 元音空间裁掉有效值 | 按选区候选扩展坐标轴；无候选时明确提示。 |
| 非校准音被接受 | 每窗检查 950–1050 Hz 能量占比至少 90%、电平至少 -70 dBFS、窗间波动不超过 1.5 dB。 |
| 校准未实际采满 5 秒 | 采集 220500 个样本才完成；7 秒超时、中断或错误均失败；末端音频也参与质量检查。 |
| 削波未识别 | PCM 达到数字满幅时拒绝言语分析和校准，使本次声级结果无效并阻止保存。 |
| 直流进入声级 | 连续录音用保持状态的 2 Hz 直流阻断器，声级与 FFT 共用该信号；离线言语信号去均值。 |
| A 计权高频扭曲 | 保留低频双二阶节，用 129 点 FIR 拟合目标与低频节的幅频响应之比，消除人为奈奎斯特零点。 |
| 单帧求根失败丢失整段结果 | 校验有限数；失败帧留空并计数，其余指标与帧仍可展示。 |

高级校准当前只接受稳定 1 kHz 纯音，不接受啭音。绝对 80 dB SPL 必须由外部参考设备确认；软件的频带与稳定性检查不能验证绝对声压。

HNR 显示的是当前分析频带内的自相关估计，不代表与其他软件或临床参考值已建立一致性。基频仍有范围限制，共振峰仍可能缺失或跟踪失败。A 计权 FIR 是有限长近似；其全频带误差、瞬态响应和设备实际频响尚未验证。

## 较早两轮审查的 8+6 项

| 问题 | 当前处理 |
| --- | --- |
| 无有效音频时显示或保存 0 | 无有效采样时显示“等待有效采样”，结果保持无效值，保存时拒绝写入。 |
| 损坏的历史校准偏移量被截成边界值 | 校准偏移量限定为 40–160 dB；历史越界值恢复为默认 100 dB，新的越界输入拒绝保存。 |
| 小数画布尺寸进入 ImageData 步长 | 创建画布、离屏画布及 ImageData 前统一取正整数尺寸。 |
| 停止言语录音时过早移除帧监听 | 保留帧监听直到录音器 `onStop` 返回，确保尾帧进入分析，再统一解除监听。 |
| 高级校准主动停止触发自动重启 | 增加主动暂停状态；主动停止、隐藏或卸载后不再自动恢复录音。 |
| Durand–Kerner 非有限残差绕过收敛判断 | 根、分母、修正量和残差均验证有限性；失败帧留空，不污染整段结果。 |
| LTAS 使用预加重信号 | LTAS 改用去均值后的原始语音；预加重只供共振峰分析使用。 |
| 过期画布查询和重试回调回写新页面 | 查询和重试绑定分析代次及页面实例；开始、复位和清理时主动取消重试定时器。 |
| 所谓“峰度惩罚”只是 10 秒极差启发式 | 删除该惩罚及相关接口；当前 CNE 明确只按 LAeq 与预计暴露时间换算，不再宣称实现峰度模型。 |
| 25、31.5 和 50 Hz 三分之一倍频程频带缺失 | FFT 长度提高到 8192，44.1 kHz 下分辨率约 5.38 Hz，使低频带具备可用频点。 |
| F0 与共振峰、强度的时间戳基准不一致 | 三类逐帧指标统一使用分析窗中心时刻。 |
| 普通校准的 2 秒定时器离页后仍执行 | 保存定时器句柄，并在隐藏、卸载和重启校准前取消。 |
| 语谱图时间标签绘制在位图范围外 | 在语谱图底部预留 18 像素时间轴区域，图像、覆盖层和选区共用有效绘图区高度。 |
| 导入的 NoiCali 文件按 Latin-1 解码 | 优先使用严格 UTF-8 `TextDecoder`，并提供校验完整的 UTF-8 回退解码器。 |

## 后续关键审查的 8 项修复

| 问题 | 当前处理 |
| --- | --- |
| 超上限 F0 被识别为低八度 | 保留范围内外局部谷并插值；范围内候选若为同样可信的超上限短周期的整数倍，返回缺失及越界原因。较弱的范围外谷不直接阻断有效候选。 |
| 宽带共振峰删除后高阶峰递补 | 仅按分析频率范围剔除候选；范围内宽带根参与编号和匹配，但不输出其数值。 |
| 未采样也能保存有效校准 | 简易校准初始禁止保存；只保存本轮成功采样生成的完整精度结果对象，失败、重采或离页清除该对象，弹窗确认时再次核对。 |
| 正常低频量化平台被判为削顶 | 连续相同极值仅标记为 plateauSuspected，不单独触发 clipped；主测量归档保留该疑点。数字满幅和近满幅仍阻断。 |
| 固定非零 PCM 产生虚假安全结果 | 检查 PCM 动态范围，识别固定值及不超过两个量化单位的输入；这类数据不增加主测量有效样本数，已有采样时使会话失效。有效结果还必须有有限且大于零的累计能量。 |
| 偏移量缺失或非数值仍被认定有效 | 校验原始存储值后再回退；损坏时先清除有效标记和元数据。写入校准时最后提交有效标记，防止中途失败沿用有效状态。 |
| 单个共振峰持续失锁 | 每个峰独立累计稳定候选，连续三帧且不与其他编号冲突时重捕获；无声或数值失败会清除待恢复计数。 |
| 静默停流保留旧的安全结果 | 活跃会话每 250 ms 检查有效输入，超过 2 秒即清空数值并使会话失效；重新初始化和退出均清理定时器。计算与保存统一检查采样新鲜度。 |

验证范围：仅进行源码复核、JavaScript 语法及差异空白检查，未执行算法测试或真机录音测试。周期歧义判断和逐峰重捕获仍是估计规则；平台疑点无法单独区分缩放后的削顶与正常整数化，不能据此保证输入未失真。
