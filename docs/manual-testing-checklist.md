# 噪声监测应用 - 功能级手测清单

## 测试环境准备

| 项目 | 要求 |
|------|------|
| 开发工具版本 | 最新微信小程序开发者工具 |
| 框架 | 无框架（原生微信小程序 WXSS/WXML/JS） |
| 测试设备 | 真机 iOS/Android 或模拟器 |
| 麦克风权限 | 已授予 |
| 位置权限 | 已授予（可选，用于测试位置记录） |
| 存储空间 | 至少 10MB 可用空间 |

## 一、主页面（Main）- 实时监测功能

### 1.1 页面加载与初始化

- [ ] **启动应用**：应用启动时无报错，main 页面正常加载
- [ ] **初始状态检查**：
  - 检查 UI 显示"噪声监测已启动"（红色指示点动画）
  - 示波器显示"暂无数据"或灰色网格
  - 尚无有效采样时，CNE、dB SPL、dBFS 均显示占位符，不显示或保存为 0.00
  - 风险等级标签显示"暂无数据"

### 1.2 监测启动流程

- [ ] **点击任何区域启动录音**：
  - 指示点开始闪烁（红色脉冲）
  - 实时声压级（dB SPL）开始滚动更新
  - Canvas 波形动画开始播放
  - 无明显卡顿或闪屏

- [ ] **检查 Canvas 渲染性能**：
  - 波形图表流畅更新（帧率 >= 30fps）
  - 网格线清晰可见
  - 瞬时边界线（阈值线）显示正确

### 1.3 数据显示正确性

- [ ] **声压级（Waveform）**：
  - dB SPL 范围合理（通常 20~130 dB）
  - dBFS 显示负值（通常 -60 ~ -10 dBFS）
  - 显示小数点后 2 位

- [ ] **累积能量（CNE）**：
  - 有效采样后显示预计暴露结果；输入声级变化时结果允许上升或下降
  - 精度：小数点后 2 位
  - 初期增速快，后期增速相对稳定（符合对数积分特性）

### 1.4 风险等级判断（5级）

#### a) 默认配置（80/85/94/105）

- [ ] **安全**（CNE < 80）：
  - 标签显示"安全"，背景色浅蓝
  - 指示点与文本颜色同为浅蓝

- [ ] **需要注意**（80 <= CNE < 85）：
  - 标签显示"需要注意"，背景色黄色
  - 整块变色正常过渡（无抖动）

- [ ] **中风险**（85 <= CNE < 94）：
  - 标签显示"中风险"，背景色橙黄色

- [ ] **高风险**（94 <= CNE < 105）：
  - 标签显示"高风险"，背景色主红
  - 文本反白（白色文字）

- [ ] **高危**（CNE >= 105）：
  - 标签显示"高危"，背景色深红
  - 文本反白

#### b) 自定义配置后的判断

- [ ] **修改分段阈值**（Settings 中调整）：
  - 修改需要注意上限为 82（从默认 85）
  - 修改中风险上限为 92（从默认 94）
  - 返回 main 页，调整后的分段生效
  - CNE 上升过程中，标签文本和颜色随新阈值变化

- [ ] **禁用中风险**：
  - Settings 中取消勾选"中风险"
  - CNE 上升过程：安全 → 需要注意 → 高风险（跳过中风险）

## 二、设置页面（Settings）- 可配置参数

### 2.1 基础参数设置

- [ ] **预期暴露时长**：
  - 初始值为 8.0 h
  - 点击 ± 按钮，精度为 0.5 h（保留 1 位小数）
  - 支持 0.5 ~ 24 h 范围

- [ ] **累计能量阈值（Slider）**：
  - 初始值 85
  - 范围 30 ~ 150
  - 步长 5
  - 改变 Slider 时 value 即时显示

- [ ] **能量单位选择**：
  - 支持"dB SPL"和"Pa²·h"两种选择
  - 选择后当前 UI 显示的单位对应实时更新

- [ ] **麦克风偏移量**：
  - 初始值 77
  - 范围 -200 ~ 200
  - Slider 调整后即时同步文本显示
  - 取值合理（不出现明显超出范围的异常）

### 2.2 风险分段配置（5级）

#### a) 基础交互

- [ ] **"需要注意"固定启用**：
  - 复选框禁用（disabled），始终勾选
  - 上限填空框默认值 85，可编辑
  - 文本提示："需要注意"为锚点分段，不能禁用

- [ ] **"中风险"复选框**：
  - 默认勾选
  - 点击取消勾选后，对应上限填空框禁用（灰色）
  - 重新勾选后恢复可编辑

- [ ] **"高风险"复选框**：
  - 默认勾选
  - 行为同"中风险"

#### b) 阈值输入验证

- [ ] **输入合理范围**：
  - 需要注意上限：输入 82（默认 85）
  - 中风险上限：输入 92
  - 高风险上限：输入 102
  - 填空框实时显示输入值

- [ ] **递增顺序校验**：
  - 需要注意 = 82，中风险 = 81（小于需要注意）
  - 点击"保存"
  - Toast 提示："分段阈值必须严格递增..."
  - 不保存，数据回滚到上次有效值

- [ ] **范围边界校验**：
  - 需要注意上限输入 75（低于最小值 ATTENTION_MAX.min）
  - 点击其他输入框（触发 blur）
  - 字段自动调整到最小值附近
  - 类似测试高边界（> ATTENTION_MAX.max）

### 2.3 保存与恢复

- [ ] **保存配置**：
  - 修改多个参数（如阈值、偏移量、超标提醒等）
  - 点击"保存"按钮
  - Toast 显示"设置已保存"
  - 2 秒后自动返回上一页

- [ ] **返回主页面验证生效**：
  - 新的风险等级和配置已生效
  - 如禁用中风险，则监测过程中不显示该等级

- [ ] **再次进入 Settings 验证持久化**：
  - onShow 时，所有自定义参数都被正确加载
  - 值与上次保存一致

- [ ] **恢复默认**：
  - 点击"恢复默认"按钮
  - 所有参数重置为工厂默认值
  - 需要点击"保存"才能生效
  - Toast 提示："已恢复默认，请点击保存"

### 2.4 其他功能

- [ ] **超标提醒开关**：
  - 默认状态为 on
  - 点击 switch 切换状态
  - 状态与 main 页的报警逻辑关联

- [ ] **麦克风权限管理**：
  - 点击"麦克风权限管理"
  - 调起微信原生权限管理页面

- [ ] **深色模式**：
  - UX 占位符，暂时无功能
  - 点击不抛出错误

## 三、监测过程中的报警与控制

### 3.1 实时报警

- [ ] **达到阈值时触发报警**：
  - 设置超标阈值为 90（通过累计能量阈值 Slider）
  - 监测过程中 CNE 上升至 90
  - 弹出 modal 对话框："警报 - 噪声累积能量预计将超过健康暴露水平"
  - 同时手机振动 5 次（每次间隔约 600ms）
  - 点击"确定"关闭报警框，监测继续

- [ ] **报警仅触发一次**：
  - 监测期间 CNE 继续上升至 95、100、110 等
  - 不再弹出报警框或振动

- [ ] **禁用报警**：
  - 返回 Settings，关闭"超标提醒"开关
  - 保存后返回 main 页
  - 重新监测，即使 CNE 超过阈值也不弹框、不振动

### 3.2 底部操作栏

- [ ] **保存记录按钮**：
  - 显示"保存记录"，背景主红色
  - 点击后弹出成功 toast："保存结果"
  - 记录被存入历史（下一节验证）

- [ ] **停止按钮**：
  - 显示"停止"，白色背景+红色边框
  - 点击后停止监测、关闭录音
  - 返回上一页（通常是首页或标签栏）

- [ ] **位置按钮**：
  - 左侧小正方形按钮，包含位置图标
  - 点击时调起"获取位置信息"加载框
  - 位置收集成功后静默保存（无提示）
  - 保存时记录位置数据到记录结构体

## 四、历史记录页面（Result）

### 4.1 记录列表展示

- [ ] **初次打开（无记录）**：
  - 显示空状态："暂无监测记录"
  - 展示默认图标
  - "清空全部"按钮不显示

- [ ] **有记录时显示列表**：
  - 每条记录显示为卡片
  - 风险色带在卡片左侧（12rpx 宽）
  - 卡片标题显示记录名称或"未命名记录"
  - 日期显示为"2026年4月1日 14:30:00"格式
  - CNE 值大字显示（右上角）

### 4.2 风险颜色映射（5级）

- [ ] **安全记录**：
  - 色带与文本为浅蓝色（SAFE）
  - 符合 main 页的颜色

- [ ] **需要注意记录**：
  - 色带与文本为黄色（ATTENTION）
  - 背景整体呈浅黄

- [ ] **中风险记录**：
  - 色带与文本为橙黄（MEDIUM）
  - 背景相对深于需要注意

- [ ] **高风险记录**：
  - 色带与文本为主红（HIGH）
  - 背景浅红

- [ ] **高危记录**：
  - 色带与文本为深红（EXTREME）
  - 背景深红

### 4.3 记录详情展开/收起

- [ ] **卡片点击**：
  - 首次点击展开，显示详细信息网格
  - 网格包含：预期暴露、记录时长、风险评估、偏移量、经纬度、采集设备
  - 高度动画平滑过渡（0 → 600rpx）
  - 不透明度从 0 → 1

- [ ] **再次点击收起**：
  - 详情区域折叠
  - 动画反向进行

### 4.4 长按操作菜单

- [ ] **长按卡片**：
  - 弹出 ActionSheet："查看记录位置"、"重命名记录"、"删除此记录"

- [ ] **查看位置**：
  - 点击后若有位置数据，调起微信内置地图
  - 地图中心显示监测地点
  - 若无位置数据，Toast 提示："没有位置信息"

- [ ] **重命名**：
  - 弹出 Modal 输入框
  - placeholderText 显示当前名称
  - 输入新名称后点击"确定"
  - 卡片标题即时更新
  - 页面数据持久化

- [ ] **删除**：
  - 确认后记录从列表移除
  - Toast 显示"已删除"
  - 列表重新渲染

### 4.5 清空全部

- [ ] **点击"清空全部"按钮**：
  - 弹出 Modal 确认："您即将删除所有记录"
  - 确认后所有记录被删除
  - 页面回到空状态
  - Toast 提示："记录已清空"

## 六、边界与异常情况

### 6.1 输入边界

- [ ] **预期暴露时长**：
  - 输入极小值（0.1）→ 自动调整到 0.5
  - 输入负值 → 忽略或调整到 0.5
  - 输入超大值（999）→ 保留但防止崩溃

- [ ] **偏移量**：
  - 输入 -300（超出范围）→ 调整到 -200（下界）
  - 输入 +300（超出范围）→ 调整到 +200（上界）

- [ ] **阈值填空**：
  - 输入非数字字符 → 忽略或显示为 NaN
  - 清空填空框 → 恢复为上次保存值
  - 小数点后的精度 → 保留合理位数

### 6.2 权限与资源

- [ ] **麦克风权限被拒**：
  - 启动监测时提示："需要麦克风权限"
  - 引导用户到权限管理页面
  - 授权后重新启动监测正常工作

- [ ] **位置权限被拒**：
  - "查看位置"操作被拒时 Toast："没有位置信息"
  - 其他功能不受影响

- [ ] **存储空间不足**：
  - 保存记录时检查存储是否可用
  - 若空间不足，Toast 提示："存储空间不足"

### 6.3 性能与稳定性

- [ ] **长时间监测（30 分钟+）**：
  - 应用无崩溃或卡死
  - 内存占用不持续增长
  - 波形图表仍然流畅

- [ ] **频繁切换页面**：
  - Main ↔ Settings ↔ Result 快速切换
  - 无状态混乱或数据丢失
  - 页面加载流畅

- [ ] **批量操作**：
  - Result 页创建 50+ 条记录不抛出异常
  - 列表滚动仍然流畅

## 常见问题排查

| 问题 | 排查步骤 |
|------|---------|
| CNE 不增长 | 检查麦克风输入是否正常、offset 是否设置正确 |
| 颜色显示错误 | 检查 CSS 变量 --ecnu-primary 等是否定义、colors.js 是否正确导入 |
| 设置保存不生效 | 清空缓存，检查 dataModel.setRiskConfig() 是否被正确调用 |
| 记录位置为空 | 检查是否授予位置权限、location 对象是否有值 |
| 波形卡顿 | 检查 Canvas 渲染频率、帧数是否达到 30fps+ |
