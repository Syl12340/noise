## 本轮继续修正

1. **跨 LPC 阶数匹配使用完整极点距离。** 旧实现只比较频率，把 2495.7 Hz / 99.4 Hz 带宽的候选匹配到 2488 Hz / 2679.2 Hz 带宽的根，忽略了 2509.9 Hz / 282.5 Hz 的候选。现同时利用极点角度与半径，解决此前唯一 F3 覆盖率失败。
2. **跨帧锚点不能覆盖当前编号。** 旧锚点可能把当前 F2 接成 F3。现先留空，再由该编号连续三个一致候选恢复。冻结信号中约 50%–60% 的大幅错号误差已消除。
3. **后台和停止状态。** 离开语音页先取消会话，迟到的 onStop 不再启动后台分析；重复开始受保护；停止等待状态可见；异常 PCM 长度使结果失效；原生 stop 抛错会清理计时器并报告错误。
4. **Worker 打包。** 原入口从 workers 目录外 require 共享模块，不符合隔离打包设计。新增确定性打包脚本，将同一源代码打入 workers 内；在 app.json 配置 workers。目录隔离测试可执行入口，且校验包未落后于源码。当前页面仍使用可取消的前台流水线。
5. **指标与能力边界。** 风险标签移到预计暴露卡片，Z 声级使用中性色；修正关于页的 16 kHz 旧描述为 44.1 kHz；共振峰显示为探索性候选，返回数据包含 quantitativeUseValidated=false。
6. **保留部分证据的宽带根。** 旧规则把“未获全部模型支持”当成“仅见于单一模型”。现只有两个相邻阶数都没有对应根时才可按附加宽带根处理；有部分证据时保留编号并拒绝不可靠数值。这一防护导致 12 kHz、F0=100/400 Hz 两个旧基准覆盖率失败，未修改测试判据。
7. **包内容清理。** 排除测试、报告、脚本、.git、编辑器配置和导出的源码文本等本地辅助文件。

## 近期主要修复

- YIN 用 CMNDF 选谷、原始差分谷插值；越界不钳位成有效上限值，不回填低八度，保留 rawF0 与拒绝原因。
- 共振峰保留各 LPC 模型的完整候选、原始编号及缺失原因；宽带根、模型冲突和重捕获均有回归。跨模型一致仍不等于真实声道共振峰准确。
- A 计权、累计能量积分、FFT/三分之一倍频程、重采样、HNR 与 LTAS 使用各自的数值回归；移除未经验证的峰度惩罚及将帧级变化率称为临床 Jitter 的描述。
- 校准区分未校准、估算参数与参考校准，绑定采集配置和安装实例，保留日期与有效期；导入不得延长原有效期。90 天为应用复核策略，不是仪器认证。
- 录音器按原生回调交接，会话所有权阻止旧帧写入；停流、无交流信号、过载及中断使测量失效、禁止保存。
- 停止后冻结摘要，可稍后保存；档案保留未舍入 LAeq/暴露级、能量、样本数、校准、参数、覆盖信息和版本。
- 无效、估算、未知及旧档案不再显示安全颜色/文字；选择分析区间会清空旧单点值，区分单点、选区及全段指标；分析可取消。

## 理论与验证边界

[Burg 共振峰分析的 Praat 官方说明](https://www.fon.hum.uva.nl/praat/manual/Sound__To_Formant__burg____.html)指出：共振峰上限与模型阶数影响结果，过高的上限可能漏掉低频峰，分析窗和预加重也会改变拟合。本项目固定 12 kHz 分析率、可选 4–5 kHz 输出上限，不能宣称适合所有说话人或与 Praat 设置完全等价。

HNR 是限带自相关估计；帧间周期变化率不是逐声门周期 Jitter。参考校准等级只说明本机完成指定流程，不证明手机全频段响应、系统增益、降噪和模拟削顶已被验证。预计暴露结果假设未来声级与测量时一致。
