# HNR移植阶段验收（2026-10-07）

结论：**独立HNR计算及受限WASM接口的桌面对照通过**，原小程序仍使用原JavaScript主线。本阶段不是完整录音HNR、真机或临床/实验室有效性发布。

## 实现及迁移层修正

- 移植去均值、前缀能量、通用512..8192点FFT自相关、重叠能量归一化、129抽头分数延迟sinc插值、Brent峰值优化及HNR/覆盖率汇总。
- 保留有声证据、最近帧严格比较、拒绝原因、峰值/延迟、收敛标记、有效时长及最低覆盖率规则；低能量、无声/不确定及采集间断边界不计为可用活动帧。
- 修正移植初稿把可变插值核再次用作固定Blackman窗的问题，分离不可变窗与工作核；修正Brent边界修正步进方向及无符号负数循环；处理Math.round半整数邻域、NaN传播、非法延迟范围及数值下溢为零时的JavaScript条件语义。
- 单次WASM输入上限8192样本、512条有声证据、128帧，整个调用共享150百万分数卷积配对预算。预算超限不发布部分结果，沿用结果确认/防覆盖和异常后弃用实例。
- 宿主仅放行声明的`env.hnr_sin`标量数学依赖；拒绝未知导入、冲突参数、非法或倒序有声证据。新增极小正基频导致延迟溢出的拒绝，避免NaN范围计算产生错误周期性估计。

## 数学依赖和交付审计

分数sinc核需要动态正弦。不同libm的末位差异可能影响Brent比较与多候选选择，因此WASM明确导入运行时的Math.sin，FFT及全部DSP仍在Rust执行，没有JavaScript DSP后备实现。默认/噪声/仅语音构建保持无导入。

原生验证注入原JS实际调用的标量正弦输入/输出轨迹，遇到未记录的输入立即失败。这验证了Rust运算和分支，但**没有验证实际原生libm后端**，不能将测试结果解释为任意原生正弦库均兼容。

DSH第一次调用因参数限制未启动；第二次MCP等待超时，后台留下两份未经验证初稿。主代理在文件稳定及工作进程核查后接手，检查并修正上述错误，实际编译和对照通过。子代理超时/不完整交付未被计为独立验收成功。
