# 本轮接口与算法移植验收

结论：**独立开发核心的桌面兼容性验证通过；尚不作为微信真机集成或科学有效性验收。** 改动位于 `rs-core`，未接入原小程序，未推送。

## 完成内容

1. 新增真实声学 WASM ABI 和独立宿主。原生 NoiseEngine 经 `wasm32-unknown-unknown` cdylib 执行，覆盖噪声的滤波、质量检查、累积能量、一秒窗口、频谱/三分之一倍频程及尾部积分。
2. 加入最多四个会话、不可复用的句柄、固定输入容量、全局待取结果保护、逐条事件转交、序列检查和错误状态。宿主在内存增长后重建视图，陷阱或已提交结果解码失败后弃用实例；不会重放已提交输入。
3. 移植 PCM 预加重、浮点预加重、YIN 单帧及轨迹计算。保留两种首采样公式，Float32 写入、Float64 运算顺序、原始 F0、拒绝原因、边界调整标记和完整帧时间。
4. 新增可复现验证入口 `tools/run-phase2.py`。原先噪声验证器通过可选 `--wasm` 后端复用相同冻结数据及数值规则，没有复制一套 JavaScript DSP 来代替 Rust 验证。

## 复核与修正

DSH负责语音源码，主代理检查实现并执行实际测试。复核时修正了“先加0.5再floor”在浮点半整数邻域不等价于JavaScript Math.round的问题，改为比较整数部分与小数部分；同时处理轨迹下一偏移可能溢出的边界。两项属于移植实现检查，未更改原始算法的科学定义。文档中对边界拒绝区间的描述也已纠正。

AGY在启动时返回API地区限制错误，没有交付源码；主代理接手接口，没有调整其账户、模型供应配置或网络。其任务记录为失败，不能计入独立验收。

## 工程与科学界限

- 语音算法目前有Rust原生调用接口，**尚未通过本噪声ABI导出到微信宿主**。重采样、HNR、LPC/共振峰、整条语音分析及断点支持逻辑尚未移植。
- WX宿主仅验证接口返回形状和无全局WebAssembly/TextDecoder条件；未在微信真机、Worker或Android录音链执行。
- 尚无600秒压力测试或手机延迟/内存保证。本接口使用完整快照和JSON频谱便于核对，其传输开销与多事件内存占用需要在独立试验中测量。
- P0对照只覆盖被冻结的核心字段；不能代表校准来源、采集完整性、风险分类、保存和UI全部通过。应用的中文失效信息映射为有界原因码，展示文本不是核心数值输出。
- 移植保留旧科学定义及已有科学验证失败，例如此前元音管线F0=400 Hz和共振峰验证未通过。逐位一致只说明计算兼容，不证明真实声压、语言病理学诊断有效性或实验室测量不确定度。
- 本轮不强制作废历史记录、不新增实验室校准使用门槛，不改变现有记录/保存行为。

后续可在相同独立目录推进语音WASM接口与抗混叠重采样，再分批迁移HNR和共振峰；整条流水线和设备验证通过前保留主线运行方式。
