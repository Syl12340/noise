# Full continuous-segment HNR sessions v1

Scope remains isolated rs-core, no production integration or policy changes. Add cooperative frame scheduling for a whole continuous analysis signal; do not split/recombine calls to the short-segment API, concatenate discontinuities or average partial means.

Core owns immutable signal/pitch/options per session. Input<=262144 Float32 samples, pitch<=4096 rows, complete frames<=4096; validate before admitting a session. Frame/time grid is baseline start=0, hop advance, complete frames only. Compute time exactly `(globalStart + frameSize/2)/fs`, never local time plus offset. Carry the forward nearest-pitch index across frames, including unchanged index on low-energy frames. Every frame reuses the existing HNR DSP and scalar sine dependency. Final HNR summary uses all ordered rows with the baseline coverage, hop-duration and minimum-duration rules.

One step processes exactly one complete frame, with a fresh150million fractional-pair budget. Commit row, cursor and counters only after successful computation. Capacity/math failure marks the session failed; no successful final result and no automatic replay. Complete and finish are idempotent; finish before all frames returns explicit incomplete status. Cancel releases owned buffers and invalidates the handle. Two sessions maximum, monotonically increasing nonzero u32 handles, no stale-handle reuse. Shared speech pending-result gate applies to creation, next, finish and cancel before mutation.

WASM has a new4096row pitch staging area; old512row short-HNR staging/capacity remain unchanged. Whole signal uses existing262144sample staging and is copied on creation. Results use the same boundedJSON/copy/ack/trap rules. Each frame receipt reports index, exact global time, progress and row. Final result contains the whole track and baseline summary. There are no persisted records or calibration checks in this interface.

Host adds asynchronous `harmonicityFull` with explicit yieldFn, onProgress and isCanceled hooks. Yield between completed frames, default setTimeout0. Copy/ack before callbacks; callback errors or cancellation release the owned session without disturbing other handles. No guarantee of interruption within a frame, worker execution or phone latency. Permit other acknowledged speech operations between yields; no arbitrary concurrent raw result consumers. Native takes explicit sine callback; WASM imports only the existing scalar Math.sin.

Freeze actual baseline whole-recording fixtures and math traces before Rust comparisons, including default5.25second/63000sample case with517pitch frames, silence/voiced transitions, sparse/near-boundary evidence, odd frame/hop, short/empty. Compare sessions with different scheduling against baseline whole execution. Use existing exact-bits/nonfinite/optional-field rules and dB<=1e-10; no new tolerance. Cancellation/ownership/stale handles/pending results/failure/no-partial-finish are separate engineering checks. Existing50HNR-state,25WASM-HNR,26noise,49pitch,70resample and defaultprobe remain regressions.

This is a full continuous HNR computation, not the full recording/phonetic pipeline: capture gaps, clipping exclusions, filter-support margins, Worker/device/Android validation, native libm qualification and LPC/formants remain separate work. No altered scientific acceptance or saving/history semantics.
