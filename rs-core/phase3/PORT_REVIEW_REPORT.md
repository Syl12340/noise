# 语音WASM接口与重采样验收（2026-10-07）

结论：适合作为**独立迁移开发阶段**提交，原小程序主线未接入；不标记为微信真机稳定版或临床/实验室科学有效性验收。

## 本轮实现

- 语音WASM导出单帧YIN、完整帧基频轨迹、PCM/浮点两种预加重及抗混叠重采样。结果使用有界JSON或独立复制的Float32缓冲区，取走后确认，未取走时拒绝新计算。
- 重采样支持12000、16000、22050、24000、32000、44100、48000Hz输入到12000Hz、5500Hz截止频率。从实际旧JavaScript的缓存写入捕获129个已归一化257抽头核，覆盖262144输入样本范围内的全部相位；未覆盖配置明确返回不支持。
- 修正移植稿把整数微相位与小数相位比较的接口错误。保留基线卷积次序、边缘保持及Float32写入，不在Rust运行时重算三角函数。
- 宿主兼容旧`hopSize`和新`hop`，拒绝冲突或未知基频参数，避免静默使用错误帧移。默认参数明确为当前小程序分析设置，调用时应显式传入参数。
- 增加长度、帧数和同步YIN比较工作量上限、内存增长后的视图重建、陷阱及解码失败后的实例弃用。没有重放、部分结果或隐式后端替换。
- 冻结导出器拒绝覆盖已有参考数据。Git属性保留`rs-core`每个文件的原始字节，防止自动CRLF/LF转换损坏科学参考哈希。验证支持从固定Git基线自动建立参考源码缓存。

## 复核说明

DSH实现了重采样算术模块，主代理复核后修正微相位类型错误并执行全部实际测试。独立只读复核提出了`hopSize`静默忽略风险，已修正并验证。复核中关于“22050Hz在i=800产生phase1”的说法被拒绝：此时位置是1470，floor同为1470，小数相位为0；实际被冻结的最大相位为0.9875。其“空轨迹返回Float32Array”和“单宿主所有权已经结构性强制”等说法也与源码不符，未计入验收证据。

单宿主所有权目前是调用契约，不能给同一个WASM实例同时挂独立噪声和语音宿主；后续集成应统一拥有实例生命周期。同步计算容量上限不是设备延迟保证，重采样也尚未实现Worker或分片调度。
